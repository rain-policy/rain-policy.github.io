# RAIN project homepage

Academic homepage for **Refine Actions If Needed: Adaptive Action Chunk Refinement for Robot Manipulation**.

- [Project page](https://rain-policy.github.io/)
- [Paper: arXiv:2610.19765](https://arxiv.org/abs/2610.19765) 路 [PDF](https://arxiv.org/pdf/2610.19765)
- [Code and citation](https://github.com/rain-policy/RAIN)
- [Pretrained models](https://github.com/rain-policy/RAIN/releases/tag/v0.1.0)

This repository contains the static homepage, figures and demonstration media.
No build or package installation is required. GitHub Pages publishes the root
of the `main` branch.

The page design is inspired by [Gated Memory Policy](https://gated-memory-policy.github.io/).

`assets/fonts/Inter-OFL.txt`.
