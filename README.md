# RAIN project homepage

Academic homepage for **Refine Actions If Needed: Adaptive Action Chunk Refinement for Robot Manipulation**.

Website: https://rain-policy.github.io/

This repository contains the static homepage, figures and demonstration media. Research implementation and pretrained-model links will be added when released.

No build or package installation is required. GitHub Pages publishes the root of the `main` branch.

The page design is inspired by [Gated Memory Policy](https://gated-memory-policy.github.io/). Inter is distributed under the SIL Open Font License, included in `assets/fonts/Inter-OFL.txt`.
